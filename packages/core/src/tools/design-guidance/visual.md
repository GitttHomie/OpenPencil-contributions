# Visual direction

Let the audience, content, references, and existing brand determine the visual direction. Preserve identity during a refinement; replace it only when the request calls for redesign. Do not enforce a preferred palette, font family, layout trend, or ban on an aesthetic the user requested.

Distinguish surfaces by their job. A marketing page may need a memorable focal point; a task-oriented interface benefits from familiar controls and consistent density; reading surfaces need comfortable measure and navigation. A product's landing page and its settings screen need not use the same degree of visual expression.

Choose a coherent type hierarchy, spacing rhythm, palette, and imagery treatment before filling the canvas. Put visual emphasis where it helps understanding or action. Repeated cards, gradients, decorative labels, and oversized headings need a purpose; equally, do not remove useful structure merely to avoid a familiar pattern.

Make corner treatment an intentional part of that direction. OpenPencil supports smooth corners as well as sharp and circular ones; use smoothing when softer surfaces suit the product, and preserve crisp geometry when it suits the audience or brand. Set it on reusable main components so related controls stay consistent, and inspect the actual curves rather than assuming a radius creates smoothing. The authoring reference gives the JSX and `set_radius` parameters.

Use available fonts and weights. Confirm loading before evaluating wrapping or alignment. Distinguish headings, labels, prose, and data through deliberate size, weight, spacing, and contrast; multiple font families are optional. Keep dense product controls readable and predictable.

Use specific, plausible copy that explains the product without inventing testimonials, credentials, customer counts, or performance claims. Align imagery with the subject and verify crop and readability. If image services are unavailable, preserve clearly described placeholders and continue useful layout work.

Inspect the rendered composition at its intended size. Check balance, hierarchy, contrast, spacing, and text flow. Resolve actual problems at their source rather than adding effects or clipping content to hide them. Stop when the requested result is coherent and verified; do not run open-ended polish loops.
